How Does Shake Detection Work?

Using the HTML5 DeviceMotionEvent API, SafeHer continuously measures total acceleration deltas: \(\sqrt{a_x^2 + a_y^2 + a_z^2}\).

Hands-Free Activation: If pinned down or unable to unlock phone screen, shaking the phone triggers emergency mode.
Safety Threshold: Tuned to prevent false alarms during normal running or walking.
